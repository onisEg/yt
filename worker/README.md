# سيرفر التفريغ المجاني (Cloudflare Worker)

ده أخف وأسرع طريقة تخلّي الصفحة تشتغل: مجاني بالكامل، من غير كارت، ومبينامش.

بيجيب الترجمة الجاهزة من يوتيوب (المرفوعة أو التلقائية) ويرجّعها نص نضيف في ثواني.

## النشر — دقيقتين

1. اعمل حساب مجاني على [dash.cloudflare.com](https://dash.cloudflare.com)
2. من القائمة: **Compute (Workers)** ← **Create** ← **Start with Hello World** ← **Deploy**
3. بعد ما يتنشر، دوس **Edit code**
4. امسح الكود اللي جواه والزق محتوى `worker.js` مكانه ← **Deploy**
5. انسخ لينك الـ Worker (شكله: `https://اسم-الـworker.اسمك.workers.dev`)
6. الصقه في «إعدادات السيرفر» في الصفحة ودوس احفظ

خلاص. من دلوقتي: لينك ← نص.

## المسارات

```
GET /health
GET /transcribe?url=LINK&lang=ar
```

## حدوده

| | |
|---|---|
| يوتيوب بترجمة جاهزة | ✅ ثواني |
| يوتيوب من غير ترجمة | ❌ استخدم تاب «ملف من جهازك» أو Colab |
| تيك توك / فيسبوك / إنستجرام | ❌ محتاجة `server/` أو Colab |

معظم فيديوهات يوتيوب عندها ترجمة تلقائية، فالوركر ده هيغطي معظم استخدامك اليومي.

## البدائل لو عايز Whisper كامل على سيرفر

مجلد `server/` فيه نسخة Docker كاملة تقدر تنشرها على [Render](https://render.com)
(الخطة المجانية فيها 512 ميجا رام — استخدم موديل `tiny` أو `base` بس) أو أي سيرفر عندك.
